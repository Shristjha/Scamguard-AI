# 🛡️ ScamGuard AI – Intelligent Scam Detection System

ScamGuard AI is a web-based scam detection project designed to help users identify suspicious messages, fraudulent SMS, emails, and potential digital scams.

The project aims to make digital communication safer through intelligent message analysis and risk detection.

## 🚀 Project Features

- **Dashboard:** Displays scam detection statistics.
- **Message Scanner:** Allows users to analyze suspicious messages.
- **Threat Detection:** Highlights potential scam activities.
- **Scan History:** Keeps track of previous message scans.
- **Security Reports:** Displays detection statistics.
- **Modern UI:** Responsive dark-themed cybersecurity dashboard.

## 🛠️ Technologies Used

## ⚙️ How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/Shristjha/Scamguard-AI.git
```

2. Navigate to the frontend folder:

```bash
cd Scamguard-AI/frontend
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the localhost URL displayed in your terminal.
